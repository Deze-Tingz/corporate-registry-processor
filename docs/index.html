Capabilities

Built for Regulatory Precision

🤖

AI Classification

Claude API classifies corporate documents into 6 types with confidence scores, field extraction, and structured reasoning. Temperature 0.0 for deterministic output.

👤

Human-in-the-Loop

Every AI classification requires human approval. Reviewers can approve, correct extracted fields, or escalate to supervisors. AI assists — humans decide.

🔒

Hash-Chained Audit Log

SHA-256 chained, append-only audit trail. Every action recorded with tamper-evident verification. 7-year retention for BVI AML compliance.

📄

OCR + Text Extraction

PyMuPDF for native PDF text. Tesseract fallback for scanned documents and images. Supports PDF, PNG, JPEG, and TIFF.

🛡

Role-Based Access Control

Four hierarchical roles: Intake Clerk, Reviewer, Supervisor, Administrator. JWT authentication with MFA (TOTP) for elevated roles.

⚡

Graceful Degradation

AI unavailable? Documents queue for manual classification. Status banner alerts reviewers. The system never stops processing.

Process

Document Lifecycle

1

Intake

Upload via drag-and-drop or filesystem watcher auto-detects new files

2

Extract

OCR extracts text from PDFs and scanned images automatically

3

Classify

Claude AI identifies document type, extracts key fields, and provides confidence

4

Review

Human reviewer verifies classification in a split-pane interface

5

Decide

Approve, correct fields, or escalate to a supervisor for complex cases

Governance

Caribbean Trusted AI Principles

📋

Transparency

AI reasoning and confidence scores visible on every classification. No black boxes.

⚖️

Accountability

Every action logged with user identity, timestamp, and hash-chain integrity.

🛡️

Human Authority

AI never makes final decisions. Humans approve, correct, or escalate every document.

🔄

Resilience

System degrades gracefully. AI failure triggers manual workflow, never data loss.
